The files in this folder are from the Unicode CLDR's JSON distribution,
release 48.2.3, each unchanged and at the path the release gives it:

https://github.com/unicode-org/cldr-json/tree/48.2.3/cldr-json

They are under the Unicode License V3, the text of which is in
src/language/bundled/LICENSE-CLDR.txt. The words Statac has for each language
but English are held to these files by a test in src/language/tests.rs, and
so is the direction every language is written in, in
src/language/direction.rs.

The files for sw are there for the example in
explanations/unknown-language.md alone, which the same tests hold to them:
Statac has no words for Swahili. The patterns each language writes a date
by, and every look a template names, are held to these files by tests in
src/language/tests.rs and src/dates/tests.rs.

Each language Statac has words for has its ca-gregorian.json,
numbers.json and delimiters.json here, and so does each of its regions
whose words, digits or patterns for dates differ from those of the tag it
inherits from, and each region whose quotation marks differ has its
delimiters.json: Statac has a file of its own for each, in
src/language/bundled/, holding only what differs. Every other region is
written as the tag it inherits from, which is why its files are not here.
The tag a region inherits from, where that is not the tag without its last
part, is given by cldr-core/supplemental/parentLocales.json, to which
src/language/parents.rs is held for every language Statac has words for.
A language in a script other than its usual one, such as en-Dsrt,
inherits from no language there, and from none in Statac, which has no
words for it; the usual script is given by
cldr-core/supplemental/likelySubtags.json.

To move to a later release, fetch the same files at its tag in place of
these and run the tests. For each language, fetch every region's
ca-gregorian.json, numbers.json and delimiters.json, as
cldr-core/availableLocales.json lists the regions, and keep those that
differ from the tag each inherits from, since a release may write another
region otherwise. Then bring the files in src/language/bundled/ and the
example to what the tests say, and name the new release wherever this one
is named.
