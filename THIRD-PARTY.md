# What Statac carries

Written by `cargo run --example third_party`.

Statac's own code is offered under MIT or Apache-2.0, at your choice. A built `statac` also carries other people's work, and each piece keeps its own licence. This is all of it. A number in square brackets is a text under [Licence texts](#licence-texts), where each text is given once.

## In the binary

### Words for dates

- What Statac has for every language but English, in `src/language/bundled/`, is from the Unicode CLDR: the names of the months and the weekdays, the words for am and pm, the quotation marks, the direction of writing and the digits. So is the usual form of a date in each of those languages, in `src/dates/format.rs`, so are English's months, weekdays and quotation marks, and so is the direction of a language Statac has no words for, in `src/language/direction.rs`: Unicode License V3. [2]

### Grammars

- 227 grammars colour code. Each is listed with its licence, its source and the notice it asks for, copyright line and all, in `THIRD-PARTY-GRAMMARS.md`, beside this file.

### The server

- The HTTP server `statac serve` answers with, in `src/serve/server/`, is the server of oxhttp 0.3.3, Copyright (c) 2018 Oxigraph developers: MIT OR Apache-2.0, taken under Apache-2.0. https://github.com/oxigraph/oxhttp. It is the server alone, without oxhttp's client; a change made to it here is marked in the file it touches. [1]

### The template engine

- The template engine that writes a site's pages, kept here in `crates/minijinja/`, is MiniJinja 3.0.1, whose licence names no copyright holder: Apache-2.0. https://github.com/mitsuhiko/minijinja. It holds part of self_cell, in `crates/minijinja/src/vendor/self_cell/`, also under Apache-2.0. A change made to the engine here is marked in the file it touches. [1]
