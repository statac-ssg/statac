# A search form's field in a template

Summary: The name and value of each hidden field in the search form that works without JavaScript.

The names (the variables a template can use) that a template reads on
each hidden field in `site.search_without_javascript.fields`.

## `name`

The field's name, for the `name` of an `<input type="hidden">`.

More: https://statac.dev/search/#without-javascript

## `value`

The field's value, such as the site's host, for the `value` of an
`<input type="hidden">`.

More: https://statac.dev/search/#without-javascript
