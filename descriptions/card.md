# A social card in a template

What a layout reads on `page.card`: the card Statac draws for the page,
or the social image its `og_image` names.

## `url`

The URL of the card's image, from the top of the host and with the
site's path. A card Statac draws is published beside the page, under a
name that changes whenever the card does.

More: https://statac.dev/sharing-cards/#in-a-layout

## `width`

The card's width in pixels: 1200 for a card Statac draws. Empty for a
social image whose size isn't known.

More: https://statac.dev/sharing-cards/#in-a-layout

## `height`

The card's height in pixels: 630 for a card Statac draws. Empty for a
social image whose size isn't known.

More: https://statac.dev/sharing-cards/#in-a-layout

## `alt`

The card's alt text: the words on a card Statac draws, or the social
image's own alt text, or else the page's title.

More: https://statac.dev/sharing-cards/#in-a-layout
