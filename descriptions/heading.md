# A heading in a template

What a template reads on each heading in `page.toc`, and in each
heading's `headings`.

## `title`

The heading's words, as plain text.

More: https://statac.dev/templates/#what-a-template-sees

## `id`

The id of the heading's element.

More: https://statac.dev/templates/#what-a-template-sees

## `url`

A link to the heading on its page: `#` and its id.

More: https://statac.dev/templates/#what-a-template-sees

## `level`

The heading's level, from 1 for a `#` heading to 6.

More: https://statac.dev/templates/#what-a-template-sees

## `headings`

The headings beneath it, each as `page.toc` gives one. Empty where there
are none.

More: https://statac.dev/templates/#what-a-template-sees
